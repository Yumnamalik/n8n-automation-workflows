# 🚀 n8n Lead Generation – Email Finder & Enrichment
![n8n Lead Generation Workflow](workflow.png)

An n8n workflow that accepts a company website, searches the domain for email addresses using Snov.io, formats the results, and saves the leads to Google Sheets.

## 🔄 Workflow

Company Website Form  
→ Get Snov.io Access Token  
→ Start Domain Search  
→ Wait for Snov.io Processing  
→ Get Domain Search Results  
→ Format Leads  
→ Save Enriched Leads to Google Sheets

## 🛠️ Tools Used

- [n8n](https://n8n.io/)
- Snov.io API
- Google Sheets
- JavaScript (n8n Code node)

## 📌 What It Does

1. A user enters a company website through the n8n form.
2. The workflow authenticates with Snov.io.
3. It starts a domain email search.
4. It waits for Snov.io to process the search.
5. It retrieves the results.
6. The Code node converts the response into lead items.
7. The leads are appended to Google Sheets.

## ⚙️ Setup

### 1. Import the workflow

Download `lead-generation-snov-github-safe.json` and import it into your n8n instance.

### 2. Configure Snov.io

Create your own Snov.io API credentials and replace:

- `YOUR_SNOV_CLIENT_ID`
- `YOUR_SNOV_CLIENT_SECRET`

with your own values in the **Get Snov Access Token** node.

### 3. Configure Google Sheets

Connect your own Google Sheets account to the **Save Enriched Leads to Google Sheets** node.

Replace:

`YOUR_GOOGLE_SHEET_ID`

with your own spreadsheet ID.

Create a sheet with columns suitable for the workflow, such as:

- email
- status
- firstName
- lastName
- position
- company
- sourceUrl

### 4. Test the workflow

Open the form generated by the **Email Finder Form** node and enter a company website.

Then execute the workflow and check the Google Sheet for the results.

## ⚠️ Important Notes

- This repository intentionally does **not** contain real API credentials.
- Always use your own Snov.io credentials and Google account.
- Never publish API keys, client secrets, access tokens, passwords, or private credentials.
- Snov.io response fields can vary by account or plan. If the **Format Leads** node returns empty fields, inspect the Snov.io response and adjust the field mappings in that node.
- The workflow includes a 30-second wait before retrieving Snov.io results. If Snov.io is still processing, increase the wait duration.
